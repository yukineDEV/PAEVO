# Pachisi Evolution (Paevo)

Repository ini berisi source code untuk **Paevo**, sebuah game board digital terinspirasi dari Ludo dengan tambahan skill-skill unik untuk menyerang lawan, dibangun menggunakan **Unity** dan **C#**.

## 📱 Tentang Aplikasi

Paevo adalah game board digital yang terinspirasi dari Ludo, namun dengan twist unik berupa skill-skill spesial yang bisa digunakan untuk menyerang lawan. Dioptimalkan untuk platform mobile, game ini menghadirkan mekanik turn-based yang strategis dengan visual 2D yang responsif.

### Fitur Utama:

1. **Turn-Based Gameplay with Unique Skills:** Mekanik giliran ala Ludo yang diperkaya dengan skill-skill unik untuk menyerang lawan, menambah lapisan strategi di setiap permainan.
2. **2D Interactive Visuals:** Visual dan animasi 2D yang dirancang untuk memodernisasi estetika board game tradisional.
3. **Cross-Platform Support:** Deployment mobile dengan pengujian performa lintas platform yang dioptimalkan untuk perangkat mobile.
